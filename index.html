How this pick works

Random gives each eligible game an equal chance. Highest-rated uses recorded Metacritic scores; newest and oldest use release years, with random picks for ties. Newest also includes dated watchlist games. Other modes exclude future/TBA games and all modes exclude expansions. Surprise Me explores different genres and unseen picks. Taste-Matched uses loved genres with a smaller penalty for dropped genres. Spinning never changes a game’s status.
